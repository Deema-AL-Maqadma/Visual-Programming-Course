# Visual Programming – Course Repository

This repository contains all materials, assignments, labs, and the final project from the **Visual Programming** course.  
It combines **theoretical foundations** with **practical implementations** in Java using NetBeans, SceneBuilder, and MySQL (XAMPP).

---

## 📚 Course Content
During the course I learned and applied the following topics:

- Fundamentals of Visual Programming with Java  
- Designing user interfaces using **FXML** and **SceneBuilder**  
- Applying **OOP concepts** in GUI applications  
- Event handling (Action, Key Pressed, Mouse Pressed)  
- Multi-stage applications (Sign Up, Sign In, Home, etc.)  
- Dialogs and input validation  
- CSS styling and linear gradient colors in SceneBuilder  
- Database integration with **MySQL (XAMPP)**  
- CRUD operations (Add, Show, Update, Delete)  
- User authentication (Sign Up, Sign In, Logout)  
- Password encryption using **MD5**  
- Validation for existing users  

---

## 📂 Repository Structure
The repository is organized as follows:

- **Assignments/**  
  Contains course assignments and labs (JavaFX exercises, FXML practice).  

- **Slides/**  
  Lecture slides covering theoretical concepts of visual programming.  

- **Fxml/**  
  Includes FXML files for UI design (login, signup, main interface, profile, etc.).  

- **Libraries and connector/**  
  Contains MySQL connector, SQL scripts, and supporting libraries.  

- **Final Project/**  
  Complete implementation of the **Library Management System** project, including documentation, UML diagrams, flow charts, and presentation materials.  

---

## 🚀 Final Project – Library Management System
I implemented a **Library Management System** as the final project.  
The project integrated **front-end UI** (JavaFX + FXML) with **back-end database** (MySQL via XAMPP).  
It included user authentication, book management, and full CRUD operations.

### Tools & Technologies:
- NetBeans  
- SceneBuilder  
- XAMPP (MySQL)  
- Word & Painter (Documentation & Flow Chart)  
- Bandicam (YouTube Recording)  
- PowerPoint (Presentation, Logo & UI Design)  

### Project Features:
- OOP concepts applied in GUI design  
- Multiple layouts and UI controls  
- Add – Show – Update – Delete – Exit operations  
- Sign Up – Sign In – Logout functionality  
- Event handling (Action, Key Pressed, Mouse Pressed)  
- Multi-stage navigation (Sign Up, Sign In, Home, etc.)  
- Dialogs and input validation  
- CSS styling in SceneBuilder  
- Database integration with MySQL  
- Password encryption using MD5
